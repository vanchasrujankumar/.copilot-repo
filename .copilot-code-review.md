# Copilot Code Review Integration

## Overview
Integrate GitHub Copilot Code Review for automated code quality checks and issue detection.

## Features

### 1. Automated Code Reviews
- **Pull Request Reviews**: Automatic reviews on PR creation
- **VS Code Integration**: Immediate feedback in editor
- **Custom Review Criteria**: Repository-specific instructions
- **Ruleset Configuration**: Automatic review triggers

### 2. Review Categories
- **Code Quality**: Clean code, SOLID principles, DRY
- **Security**: Vulnerabilities, input validation, secrets
- **Performance**: Algorithm efficiency, memory usage
- **Testing**: Test coverage, edge cases, integration
- **Documentation**: Comments, README, API docs

### 3. Integration Points
- **GitHub Actions**: Automated review workflows
- **VS Code**: Real-time feedback
- **GitHub UI**: Pull request comments
- **CLI**: Command-line review tools

## Setup Instructions

### 1. Enable Copilot Code Review
```bash
# Ensure Copilot subscription is active
# Enable code review features in Copilot settings
```

### 2. Configure Repository Rules
```yaml
# .github/copilot-code-review.yml
code_review:
  enabled: true
  auto_review: true
  required_checks:
    - security
    - performance
    - testing
  custom_instructions: |
    Focus on:
    - Event-driven architecture patterns
    - Java microservices best practices
    - MongoDB query optimization
    - Kafka producer/consumer patterns
    - TDD with 100% coverage
```

### 3. VS Code Configuration
```json
// .vscode/settings.json
{
  "github.copilot.codeReview.enabled": true,
  "github.copilot.codeReview.autoReview": true,
  "github.copilot.codeReview.categories": [
    "security",
    "performance",
    "testing",
    "documentation"
  ]
}
```

## Review Workflow

### 1. Pre-commit Review
```bash
# Run Copilot review before committing
npx @github/copilot-code-review --pre-commit
```

### 2. Pull Request Review
```yaml
# .github/workflows/copilot-review.yml
name: Copilot Code Review
on: [pull_request]
jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: github/copilot-code-review-action@v1
        with:
          categories: "security,performance,testing"
          custom_instructions: "Review for event-driven patterns and TDD"
```

### 3. Continuous Review
```yaml
# .github/workflows/continuous-review.yml
name: Continuous Code Review
on:
  push:
    branches: [main, develop]
  schedule:
    - cron: '0 0 * * *'  # Daily review
jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: github/copilot-code-review-action@v1
```

## Integration with Multi-Agent System

### Orchestrator Integration
```javascript
// Orchestrator uses Copilot Code Review
const reviewResult = await copilotCodeReview.review({
  code: changes,
  categories: ['security', 'performance', 'testing'],
  customInstructions: 'Focus on event-driven patterns'
});

// Route to specialist agents based on review findings
if (reviewResult.securityIssues.length > 0) {
  await securityEngineer.review(reviewResult.securityIssues);
}
if (reviewResult.performanceIssues.length > 0) {
  await javaArchitect.optimize(reviewResult.performanceIssues);
}
```

### Self-Learning Integration
```javascript
// Learn from review patterns
selfLearningAgent.learn({
  pattern: 'common_security_issues',
  examples: reviewResult.securityIssues,
  solutions: reviewResult.suggestedFixes
});

// Store successful review patterns
knowledgeBase.store({
  type: 'code_review_pattern',
  pattern: 'event_driven_best_practices',
  examples: successfulReviews,
  metrics: { successRate: 0.95 }
});
```

## Best Practices

### 1. Review Frequency
- **Pre-commit**: Every commit
- **Pull Request**: Every PR
- **Scheduled**: Daily automated reviews
- **Manual**: On-demand deep reviews

### 2. Review Scope
- **New code**: Full review
- **Modified code**: Diff review
- **Critical paths**: Deep review
- **Dependencies**: Security review

### 3. Feedback Quality
- **Actionable**: Specific fixes
- **Educational**: Explain why
- **Prioritized**: Critical first
- **Constructive**: Positive tone

### 4. Performance
- **Fast reviews**: < 30 seconds
- **Incremental**: Review changed lines
- **Cached**: Reuse previous reviews
- **Parallel**: Review multiple files

## Troubleshooting

### Common Issues
1. **Slow reviews**: Check network, increase timeout
2. **False positives**: Adjust custom instructions
3. **Missing reviews**: Verify Copilot subscription
4. **Integration issues**: Check configuration files

### Debug Commands
```bash
# Test Copilot connectivity
npx @github/copilot-code-review --test

# Review specific file
npx @github/copilot-code-review --file src/main/java/Example.java

# Get review statistics
npx @github/copilot-code-review --stats
```
