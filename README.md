# Global Copilot Repository

This repository contains skills and agents for AI-assisted development with GitHub Copilot.

## Structure

- **skills/** - Reusable skills for different technologies and approaches
- **agents/** - Role-specific agents with specialized capabilities
- **workspace/** - Clone your personal repos here to use these skills

## Available Skills

### Global Skills
- Event-driven systems
- Java microservices
- MongoDB
- Kafka
- Grafana
- Vela
- Spark, Scala, Hive, BigQuery
- Shell, Python, Node.js, npm, JavaScript
- Playwright (testing)

### Role-Specific Skills
- Full Stack Engineer
- Java Architect
- DevOps Engineer
- Security Engineer
- Data Engineer
- QA Tester

## Usage

1. Clone your personal repos to the `workspace/` directory
2. Configure Copilot to use skills from this repo
3. Use role-specific agents for targeted assistance

## Data-Driven & Test-Driven Approach

All skills follow:
- **Data-driven**: Based on real-world patterns and best practices
- **Test-driven**: Emphasize TDD/BDD with comprehensive test coverage
