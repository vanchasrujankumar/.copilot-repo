# Data Engineer Skill

## Overview
Expertise in building and maintaining data pipelines, data warehouses, and analytics infrastructure.

## Core Competencies

### Data Pipeline Development
- **ETL/ELT**: Extract, Transform, Load processes
- **Batch Processing**: Scheduled data processing
- **Stream Processing**: Real-time data processing
- **Data Ingestion**: APIs, files, databases, streaming

### Data Warehousing
- **BigQuery**: Google Cloud data warehouse
- **Snowflake**: Cloud data platform
- **Redshift**: AWS data warehouse
- **Synapse**: Azure data warehouse

### Data Processing Frameworks
- **Apache Spark**: Distributed data processing
- **Apache Flink**: Stream processing
- **Apache Kafka**: Real-time data streaming
- **Apache Airflow**: Workflow orchestration

### Data Modeling
- **Star Schema**: Fact and dimension tables
- **Snowflake Schema**: Normalized dimensions
- **Data Vault**: Audit trail modeling
- **Anchor Modeling**: Historical modeling

## Key Technologies

### Data Storage
- **Object Storage**: S3, GCS, Azure Blob
- **Data Lakes**: Delta Lake, Iceberg, Hudi
- **Databases**: PostgreSQL, MySQL, MongoDB
- **Data Warehouses**: BigQuery, Snowflake, Redshift

### Data Processing
- **SQL**: Complex queries, window functions
- **Python**: Pandas, PySpark
- **Scala**: Spark development
- **Java**: Spark applications

### Orchestration
- **Airflow**: DAG management
- **Prefect**: Modern workflow orchestration
- **Dagster**: Data orchestration
- **Luigi**: Task management

## Data Quality

### Validation
- **Schema Validation**: Data type and structure
- **Completeness**: Missing value checks
- **Uniqueness**: Duplicate detection
- **Consistency**: Cross-field validation
- **Accuracy**: Data correctness

### Monitoring
- **Data Freshness**: Update timing
- **Data Volume**: Expected record counts
- **Data Distribution**: Statistical checks
- **Anomaly Detection**: Unexpected patterns

## Data Governance

### Metadata Management
- **Data Catalog**: Asset discovery
- **Lineage**: Data provenance
- **Tags**: Classification
- **Ownership**: Data stewardship

### Compliance
- **Data Privacy**: GDPR, CCPA
- **Data Security**: Encryption, access control
- **Audit Trails**: Change tracking
- **Retention Policies**: Data lifecycle

## Best Practices

1. **Data Pipeline Design**
   - Idempotent operations
   - Error handling and retries
   - Monitoring and alerting
   - Version control for pipelines

2. **Data Quality**
   - Implement validation at source
   - Monitor data quality metrics
   - Automated data testing
   - Data documentation

3. **Performance Optimization**
   - Partitioning and clustering
   - Query optimization
   - Caching strategies
   - Resource management

4. **Security**
   - Data encryption
   - Access control
   - Audit logging
   - Secret management

5. **Documentation**
   - Data dictionaries
   - Pipeline documentation
   - Data lineage
   - Runbooks

## Common Workflows

### Building a Data Pipeline
1. Define requirements
2. Design schema
3. Extract data from sources
4. Transform and clean data
5. Load to destination
6. Validate data quality
7. Set up monitoring
8. Document the pipeline

### Data Modeling
1. Understand business requirements
2. Identify facts and dimensions
3. Design schema
4. Implement tables
5. Create views and aggregates
6. Optimize for query performance
