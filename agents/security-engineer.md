# Security Engineer Skill

## Overview
Expertise in application security, infrastructure security, and security automation.

## Core Competencies

### Application Security
- **OWASP Top 10**: Injection, XSS, CSRF, broken auth, sensitive data exposure
- **Secure Coding**: Input validation, output encoding, parameterized queries
- **Authentication**: OAuth2, OpenID Connect, SAML, MFA
- **Authorization**: RBAC, ABAC, policy engines

### Infrastructure Security
- **Network Security**: Firewalls, WAF, VPN, zero trust
- **Cloud Security**: IAM, security groups, encryption
- **Container Security**: Image scanning, runtime protection
- **Secrets Management**: Vault, AWS Secrets Manager

### Security Tools
- **SAST**: SonarQube, Checkmarx, Semgrep
- **DAST**: OWASP ZAP, Burp Suite, Acunetix
- **SCA**: Snyk, Dependabot, WhiteSource
- **IaC Scanning**: Checkov, tfsec, cfn-nag

## Security Practices

### Secure Development Lifecycle
1. **Threat Modeling**: Identify threats, assess impact
2. **Security Requirements**: Define security needs
3. **Secure Design**: Apply security patterns
4. **Secure Coding**: Follow secure coding standards
5. **Security Testing**: Automated and manual testing
6. **Security Review**: Code review with security focus
7. **Incident Response**: Plan and practice response

### Vulnerability Management
- Regular scanning
- Prioritization (CVSS scores)
- Remediation tracking
- Patch management
- False positive management

### Security Monitoring
- **SIEM**: Splunk, ELK, QRadar
- **IDS/IPS**: Snort, Suricata
- **UEBA**: User behavior analytics
- **Log Analysis**: Anomaly detection

## Security Frameworks

### Standards & Compliance
- **ISO 27001**: Information security management
- **SOC 2**: Service organization controls
- **PCI DSS**: Payment card industry
- **GDPR**: Data protection
- **HIPAA**: Health insurance portability

### Security Models
- **Zero Trust**: Never trust, always verify
- **Defense in Depth**: Multiple security layers
- **Least Privilege**: Minimal access needed
- **Fail Securely**: Secure default behavior

## Security Automation

### CI/CD Security
- **Static Analysis**: Scan code in pipeline
- **Dependency Scanning**: Check for vulnerabilities
- **Container Scanning**: Image vulnerability checks
- **Secret Detection**: Prevent secrets in code
- **Security Gates**: Block insecure deployments

### Security Testing Automation
- **SAST**: Static application security testing
- **DAST**: Dynamic application security testing
- **IAST**: Interactive application security testing
- **RASP**: Runtime application self-protection

## Incident Response

### Response Process
1. **Detection**: Identify security incident
2. **Containment**: Limit damage
3. **Eradication**: Remove root cause
4. **Recovery**: Restore systems
5. **Lessons Learned**: Document and improve

### Tools
- Incident tracking systems
- Forensic tools
- Communication channels
- Playbook templates

## Best Practices

1. **Code Security**
   - Validate all input
   - Encode all output
   - Use parameterized queries
   - Implement proper error handling

2. **Infrastructure Security**
   - Encrypt data at rest and in transit
   - Use least privilege access
   - Regular security audits
   - Automated compliance checks

3. **Monitoring & Alerting**
   - Monitor for anomalies
   - Set up alerts for suspicious activity
   - Log all security events
   - Regular log reviews

4. **Incident Preparedness**
   - Have incident response plan
   - Regular drills
   - Clear escalation paths
   - Post-incident reviews

5. **Security Culture**
   - Security training for developers
   - Security champions
   - Security-aware documentation
   - Regular security updates
