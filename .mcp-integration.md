## Sequential Thinking Server

### Features
- **Step-by-step reasoning**: Break complex problems into manageable steps
- **Revision capability**: Revise and refine thoughts as understanding deepens
- **Branching**: Explore alternative paths of reasoning
- **Dynamic adjustment**: Adjust total number of thoughts as needed
- **Solution verification**: Generate and verify solution hypotheses

### Tool: `sequential_thinking`
**Inputs:**
- `thought` (string): Current thinking step
- `nextThoughtNeeded` (boolean): Whether another thought step is needed
- `thoughtNumber` (integer): Current thought number
- `totalThoughts` (integer): Estimated total thoughts needed
- `isRevision` (boolean, optional): Whether this revises previous thinking
- `revisesThought` (integer, optional): Which thought is being reconsidered
- `branchFromThought` (integer, optional): Branching point thought number
- `branchId` (string, optional): Branch identifier
- `needsMoreThoughts` (boolean, optional): If more thoughts are needed

### Use Cases
- **Complex problem solving**: Database migrations, architecture design
- **Debugging**: Step-by-step analysis of production issues
- **Planning**: Multi-step project planning with course correction
- **Analysis**: Deep analysis with room for revision

## Setup Instructions

### 1. Install MCP Servers
```bash
# Install Sequential Thinking
npm install -g @modelcontextprotocol/server-sequential-thinking

# Install other MCP servers
npm install -g @modelcontextprotocol/server-github
npm install -g @modelcontextprotocol/server-postgres
npm install -g @modelcontextprotocol/server-slack
npm install -g @modelcontextprotocol/server-jira
npm install -g @modelcontextprotocol/server-notion
```

### 2. Configure Environment Variables
```bash
# Create .env file
cp .env.example .env

# Edit .env with your credentials
# Sequential Thinking
DISABLE_THOUGHT_LOGGING=false

# Other MCP servers
GITHUB_TOKEN=your_github_token
POSTGRES_CONNECTION_STRING=postgresql://user:pass@host:port/db
SLACK_BOT_TOKEN=your_slack_bot_token
JIRA_API_TOKEN=your_jira_token
JIRA_BASE_URL=https://your-domain.atlassian.net
NOTION_API_KEY=your_notion_api_key
KAFKA_BOOTSTRAP_SERVERS=localhost:9092
GRAFANA_URL=https://grafana.example.com
GRAFANA_API_KEY=your_grafana_api_key
GCP_PROJECT_ID=your-gcp-project
GCP_CREDENTIALS=path/to/credentials.json
```

### 3. Start MCP Servers
```bash
# Start all configured servers
npm run mcp:start
```

## Integration with Agents

### Agent-MCP Communication
```javascript
// Example: Agent using Sequential Thinking
const sequentialThinking = new MCPClient('sequential-thinking');
const thought = await sequentialThinking.think({
  thought: "Analyzing database migration requirements",
  nextThoughtNeeded: true,
  thoughtNumber: 1,
  totalThoughts: 5
});
```

### Common Patterns

#### 1. Sequential Problem Solving
```javascript
// Step-by-step problem solving
let thoughtNumber = 1;
let totalThoughts = 10;
let nextThoughtNeeded = true;

while (nextThoughtNeeded && thoughtNumber <= totalThoughts) {
  const result = await sequentialThinking.think({
    thought: `Step ${thoughtNumber}: Analyzing component ${component}`,
    nextThoughtNeeded: thoughtNumber < totalThoughts,
    thoughtNumber,
    totalThoughts
  });
  
  thoughtNumber++;
  nextThoughtNeeded = result.nextThoughtNeeded;
}
```

#### 2. Revision Pattern
```javascript
// Revise previous thinking
await sequentialThinking.think({
  thought: "Revised analysis based on new information",
  nextThoughtNeeded: true,
  thoughtNumber: 3,
  totalThoughts: 8,
  isRevision: true,
  revisesThought: 2
});
```

#### 3. Branching Pattern
```javascript
// Explore alternative paths
await sequentialThinking.think({
  thought: "Alternative approach to the problem",
  nextThoughtNeeded: true,
  thoughtNumber: 4,
  totalThoughts: 10,
  branchFromThought: 3,
  branchId: "alternative-approach"
});
```
